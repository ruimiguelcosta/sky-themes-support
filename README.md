| Plugin | Component | Moodle |

## Report a bug or ask for a feature

[Open an issue](../../issues/new/choose) and choose the form that fits. Please include:

- the theme or plugin and its version (Site administration > Plugins > Plugins overview);
- your Moodle version;
- the steps to reproduce the problem, and a screenshot if you can.

Before opening a new issue, search the [existing issues](../../issues?q=is%3Aissue) in case it has already been reported.

Do not post passwords, site URLs you want to keep private or personal data of your users.

## Documentation

Installation, settings and requirements are described in the `README.md` file inside each theme package.

Common questions:

- **The site home shows the login page instead of the hero.** Turn off "Force users to log in"
  (Site administration > Security > Site security settings). On Moodle 5.3, also check that
  "Enable Home" is on (Site administration > Appearance > Navigation).
- **Texts are in English only.** Install the Moodle language pack for your language; the theme
  translations (pt, pt_br, es, fr, de, it) are distributed through AMOS.
